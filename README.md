# Wager Watch Landing Page

Static landing page for GitHub Pages.

## Files
- `index.html`
- `styles.css`

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload both files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select your default branch and `/ (root)`, then save.
6. Add your custom domain in the GitHub Pages settings when ready.
